## 1. حدود الـdry run

- المشاركون في التدريب أعضاء الفريق/الباحث فقط، ولا يستخدم طالب أو مرشح أو بيانات شخص حقيقي.
- يستخدم السيناريو والبيانات الخيالية الموجودة في النموذج حرفيًا.
- لا تسجل REP/OBS بوصفها participant evidence؛ المسموح فقط operational problems في النص أو النموذج أو السلامة.
- لا يُملأ evidence matrix ولا dashboard ولا task-success matrix بنتائج تمثيلية.
- التسجيل الصوتي/المرئي وtranscript/AI note-taker معطلة حتى في التدريب.
- لا نشر أو إرسال أو إنشاء نموذج فرز أو جدولة نتيجة تنفيذ التدريب.

## 5. تمارين السلامة والحالات الاستثنائية

### 5.1 معلومة حساسة عرضية

يتدرب المحاور على العبارة:

> سأتوقف هنا لحماية خصوصيتك. لا نحتاج هذه المعلومة. لن أنقلها إلى الملاحظات، وسأحذف/أطمس أي أثر مؤقت قبل أن نقرر معًا إن كنا سنكمل.

- [ ] يوقف السؤال أو المهمة فورًا.
- [ ] لا يكرر المحتوى الحساس في incident log.
- [ ] يزيل المسودة/clipboard وفق العملية ويستدعي Data Steward إذا لزم.

### 5.2 انسحاب

> بالتأكيد. سنوقف الجلسة الآن، ولا تحتاج إلى ذكر سبب. سأطبق خيار إيقاف التواصل/الانسحاب/الحذف وفق الورقة المعتمدة وأؤكد لك عبر وسيلة البحث.

- [ ] يتوقف فورًا ولا يحاول إقناع الشخص بالبقاء.
- [ ] يميز وقف التواصل عن حذف المواد القابلة للربط.
- [ ] يعرف cut-off ومسار التصعيد — ويعد التدريب غير جاهز إذا لم يكونا معتمدين.

### 5.3 فشل النموذج

- [ ] يسجل `Prototype blocked` تشغيليًا، لا خطأ مستخدم.
- [ ] لا ينتقل إلى نسخة سحابية أو remote workaround.
- [ ] يعرض إيقاف قسم UT1 أو إعادة جدولة اختيارية فقط.
- [ ] يحفظ المقابلة السلوكية منفصلة إذا كانت صالحة وموافقًا عليها.

### 5.4 إغلاق بلا بيع

يتدرب المحاور على:

> انتهت الجلسة. هذا النموذج ليس منتجًا أو وعد إطلاق، ولا يعني البحث أن ميزة ستُبنى. هل أخطأنا في تلخيص طريقتك؟ سأذكرك فقط بحقوق الانسحاب والحذف والحافز المعتمد.

- [ ] لا يسأل «هل ستستخدم المنتج؟» بصيغة بيع.
- [ ] لا يعد roadmap أو PRD أو إطلاقًا أو وصولًا مبكرًا.
- [ ] لا يطلب إحالات قبل اعتماد قناة الإحالة ونصها.
