- عدم طلب IP أو بريد أو تسجيل دخول؛ إذا كانت المنصة تجمعها تلقائيًا يجب تعطيله أو الإفصاح عنه.

## 14. خطة التحليل — بلا بيانات مخترعة

### 14.1 المخرجات الوصفية

- مخطط تدفق يوضح عدد من فتحوا، وافقوا، تأهلوا، أكملوا، واستُبعدوا مع الأسباب.
- توزيع Q4 للمصادر المستخدمة، وQ5 لمصدر الثقة، وQ6 لأول إجراء.
- نطاقات تكرار البحث والنقل والتأخير والتغيير، مع المقام و`لا أتذكر` منفصلًا.
- device × first capture، وlanguage mix × RTL friction.
- onboarding tolerance حسب workflow الحالي، مع التنبيه أن الإجابة متوقعة لا سلوكًا ملاحظًا.
- تفضيل النتيجة forced-choice حسب الشريحة لا كتصويت roadmap.
- تكرار كل مهمة AI، وطريقة تنفيذها الحالية، ونسبة الصفر/عدم الانطباق.

### 14.2 مقارنات مخططة

تقارن وصفيًا، إن كان حجم الخلايا مناسبًا:

- منظم رقميًا مقابل هجين/ورق/ذاكرة.
- مستخدم LMS كمصدر ثقة مقابل تقويم شخصي.
- سنة مبكرة مقابل متقدمة.
- جدول ثابت مقابل متغير.
- عربي/مختلط/إنجليزي.
- هاتف أولًا مقابل غيره.

لا تُنشر خلايا صغيرة قد تكشف أفرادًا. لا تُجرى عشرات اختبارات دلالة استكشافية ثم تنتقى النتائج. أي تحليل استدلالي يحتاج خطة مسبقة وعينة مناسبة ومراجعًا منهجيًا.

## 15. التجربة المصغرة قبل النشر

مع 5–8 أشخاص غير داخل التحليل الرئيسي:

1. think-aloud لفهم الفترة المرجعية و`لا ينطبق`/`لا أتذكر`.
2. قياس زمن واقعي على الهاتف.
3. فحص ظهور skip logic واتجاه RTL والنص المختلط.
4. سؤال المشارك عما ظنه الهدف بعد الإكمال لكشف priming.
5. تسجيل كل تعديل مع السبب والإصدار.
6. عدم فتح الاستبيان العام قبل مراجعة المالك والخصوصية.
