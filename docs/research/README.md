## 3. ترتيب الاستخدام المطلوب

1. **تثبيت baseline:** قراءة Deliverable 1 v0.2 وDeliverable 2 outline و02a وهذا README.
2. **إكمال 03g:** يملأ المالك الحقول العشرين الحقيقية ويحل placeholders المشاركة؛ لا تخمين.
3. **Dry run داخلي:** تنفيذ 03h على حاسوب الباحث، وإغلاق المشكلات الحاجبة؛ لا مشارك ولا user evidence.
4. **اعتماد الخصوصية والتشغيل:** التخزين والصلاحيات والاحتفاظ والحذف والاتصال والقنوات والحافز والمكان؛ التسجيل يبقى معطلًا.
5. **تصريح G1 صريح:** لا تُرسل أو تُنشر رسالة قبل توقيع صاحب الصلاحية المحدد في 03g.
6. **التجنيد المحدود:** الوصول إلى 8 مقابلات صالحة فقط، لطلاب بكالوريوس حاليين في جامعات سعودية، 18+.
7. **المقابلات السلوكية أولًا:** 45–60 دقيقة، حضوريًا، notes-only، باستخدام `INT-###`.
8. **R1 subset:** خمسة من المشاركين الثمانية فقط، بعد إكمال المقابلة وموافقة استمرار منفصلة؛ الجلسة المشتركة 75–90 دقيقة.
9. **تركيب منفصل:** `UT1-###` منفصل عن `INT-###`؛ لا يعد التحقق التقني أو قول المقابلة task success.
10. **Round 2 فقط عبر البوابة:** لا يبدأ تلقائيًا؛ يجب تحقق شروط Round 2 واعتماد المالك.
11. **اليوميات والاستبيان الواسع:** يظلان مؤجلين ما لم تظهر حاجة دليلية محددة من المقابلات/R1 ويصدر اعتماد منفصل.
12. **التركيب والقرار:** تعبئة 02h من Source IDs وعقد بوابة Proceed/Narrow/Pivot/Stop.
13. **PRD:** لا يبدأ إلا بعد قرار Proceed أو Narrow صريح؛ لا يصرّح ذلك تلقائيًا بـSRS أو architecture أو code.

## 4. الفصل بين الخطة والدليل

### خطط وأدوات فقط

`02a` و`02c` و`02d` و`02e` و`02f` و`02g` و`02h` و`03a`–`03e` و`03g` و`03h` في نسختها الحالية. الأمثلة داخلها خيالية لتوضيح البروتوكول ولا تُنقل إلى evidence matrix؛ dry run في 03h ينتج مشكلات تشغيلية فقط.

### دليل موجود حاليًا

`02b` بحدود desk research، و`03f` بحدود تحقق تقني أجراه الباحث على artifact خيالي. لا يثبت أي منهما سلوك طالب أو نجاح مهمة أو قبول حل. `[INF]` ليس حقيقة، و`[NV]` ليس فجوة سوقية.

### دليل لم يوجد بعد

مقابلات، اقتباسات، diary events، survey responses/numbers، usability task results، intent/retention، أو مقارنة AI من مشاركين. حالتها دائمًا `PENDING` حتى جمعها فعلًا.

## 5. تخزين دليل المشاركين لاحقًا

لا يُنشأ مخزن participant evidence قبل اعتماد الموقع والصلاحيات والاحتفاظ. بعد الاعتماد، يقترح 02h فصلًا منطقيًا:

- بيانات الاتصال/الجدولة في مكان مؤقت منفصل.
- الموافقات بصلاحيات محدودة.
- ملاحظات/تفريغات منقحة تحمل IDs فقط.
- بيانات survey منزوعة الهوية وقاموس بيانات.
- synthesis matrices لا تحتوي تفاصيل يمكن ربطها.

أسماء المعرفات:

- `INT-###` للمقابلات.
- `DIA-###` لليوميات، و`DIA-###-E##` للأحداث.
- `SUR-###` للاستبيان إن احتجنا record ID عشوائيًا.
- `UT1-###` و`UT2-###` لاختبارات النموذج.
- `EV-###` للأدلة و`CL-###` للادعاءات.

لا تحفظ بيانات الاتصال في Git أو هذا المجلد الوثائقي. لا ترفع تسجيلات أو consent records إلى المستودع.

## 6. قيود الخصوصية

- لا رقم جامعي، هوية، درجات، GPA، ملفات مقررات، أسماء مقررات/محاضرين حقيقية، لقطات LMS أو جداول كاملة.
- موافقة المشاركة منفصلة عن موافقة الاستمرار للنموذج والاقتباس المنقح.
- التسجيل الصوتي/المرئي وtranscript/AI note-taker معطلة في Sprint 1، ولا تُعرض كموافقة اختيارية.
- أقل بيانات لازمة، وفصل الاتصال عن التحليل، وطمس عرضي سريع.
- حق التخطي والانسحاب والحذف حتى تاريخ القطع المعلن.
- عدم نشر خلايا صغيرة أو سياقات مركبة تكشف شخصًا/برنامجًا نادرًا.
- الاحتفاظ المقترح في 02a لا يصبح سياسة قبل موافقة ومراجعة خصوصية/قانونية.
- مرجع تنظيمي عام: [نظام حماية البيانات الشخصية — سدايا](https://sdaia.gov.sa/en/SDAIA/about/Documents/Personal%20Data%20English%20V2-23April2023-%20Reviewed-.pdf). الوثائق ليست مشورة قانونية.

## 7. قاعدة منع البحث الملفق

ممنوع:

- إنشاء مشارك أو اقتباس أو جلسة أو diary entry أو survey response أو نتيجة usability خيالية بوصفها دليلًا.
- ملء قوالب 02h من توقعات الفريق.
- تحويل مثال fictional في 02g إلى «نجح المستخدم».
- تقدير نسبة أو متوسط أو market size بلا بيانات ومصدر ومنهج.
- حذف evidence against أو حالات الانسحاب لإظهار نتيجة أوضح.
- اعتبار محتوى generated/synthetic بديلًا عن طالب حقيقي.

إذا تعذر الوصول لمشارك أو مصدر، يكتب `PENDING` أو `Not verified` مع السبب. الغياب ليس تصريحًا بالتخمين.

## 8. وسوم الأدلة الإلزامية

- `AD` قرار معتمد.
- `P` مقترح.
- `H` فرضية.
- `VF` حقيقة مصدر رسمي.
- `OBS` سلوك شاهده الباحث.
- `REP` قول/تقرير مصدر أو مشارك.
- `INF` تفسير.
- `NV` غير متحقق.
- `PENDING` لم يجمع بعد.

كل استنتاج في synthesis يجب أن يعود إلى Source IDs، ويسجل evidence for and against وحدود الثقة.
