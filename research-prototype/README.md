# StudentHub AI — Disposable Research Prototype

> **ARCHIVED DISPOSABLE ARTIFACT — 5 August 2026:** Research testing was cancelled. This prototype is not production code, must not be copied or promoted into the production application, and does not constrain the active architecture in `../docs/product/`.

> **تحذير واضح:** هذا نموذج بحث قابل للرمي، وليس تطبيق StudentHub AI الحقيقي أو أساسًا لكود الإنتاج.

## الغرض

هذا المجلد يدعم جلسات Validation Sprint 1 الخاضعة للإشراف فقط. يحتوي تجربة محلية مبسطة لاختبار فهم تدفقات القلب التنظيمي باستخدام بيانات خيالية.

## طريقة Round 1 المعتمدة

- الاختبار حضوري على حاسوب الباحث، باستخدام هذه النسخة المحلية فقط.
- remote prototype testing غير مصرح به في Round 1 ما لم يسبق ذلك dry run تقني منفصل واعتماد جديد يثبت تحكم المشارك المباشر.
- التسجيل الصوتي والمرئي وtranscript/AI note-taking معطلة؛ الملاحظات فقط.
- لا يُطلب من المشارك إدخال أي معلومة حقيقية أو استخدام جهازه أو فتح LMS أو مشاركة شاشة.
- يعاد ضبط النموذج وتفحص البيانات الخيالية قبل كل جلسة وبعدها.
- نجاح التحقق التقني لا يساوي user validation؛ كل نتائج المشاركين `PENDING` حتى تنفيذ جلسات مصرح بها.

## قيود ملزمة

- ليس تطبيق إنتاج، ولا يجوز تحويله إلى نقطة بداية للتطبيق الحقيقي.
- لا يحدد أو يوصي بالتقنيات أو المعمارية أو الـstack المستقبلية.
- لا backend، قاعدة بيانات، مصادقة، API، تخزين سحابي أو نشر.
- لا إشعارات حقيقية، analytics، tracking، cookies أو تخزين محلي دائم.
- لا AI أو اتصال بمزود AI؛ بطاقات المفاهيم نصوص ثابتة كتبها الباحث.
- لا external network requests أو مكتبات أو خطوط أو صور خارجية.
- لا بيانات جامعة أو مشارك حقيقية؛ البيانات كلها خيالية من خطة الاختبار المعتمدة.
- يجب أرشفته أو التخلص منه بعد انتهاء البحث، وألا يُنسخ إلى مستودع الإنتاج.

## التشغيل المحلي

الخيار الأبسط: افتح `index.html` مباشرة في متصفح حديث.

إذا منع المتصفح بعض السلوك المحلي، يمكن استخدام خادم محلي موجود مسبقًا، مثل:

```powershell
python -m http.server 8765 --directory research-prototype
```

ثم افتح `http://127.0.0.1:8765/`. لا يلزم تثبيت أي حزمة.

- `styles.css` — تصميم mobile-first وRTL بلا أصول خارجية.
- `app.js` — حالة مؤقتة داخل الذاكرة وتفاعلات الاختبار فقط.
